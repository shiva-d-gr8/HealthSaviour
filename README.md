# HealthSaviour

## Overview

HealthSaviour is a full-stack doctor appointment booking web application built using the MERN stack. The platform allows users to book appointments with doctors, manage profiles, receive notifications, and perform secure authentication operations.

## Features

User Features:

- User registration and login

- JWT-based authentication

- Book doctor appointments

- View appointment history

- Update user profile

- Password reset functionality

- Real-time notifications

Doctor Features:

- Doctor profile management

- View patient appointments

- Accept or reject appointments

Admin Features:

- Manage doctors

- Manage users

- View all appointments

- Application approval system
